# Security Policy

Resumes and job descriptions can contain sensitive personal data. Do not publish real resumes, contact details, private job documents, credentials, or exploitable details in public issues or pull requests.

Use GitHub's Security tab and **Report a vulnerability** flow for private disclosure when enabled. If unavailable, contact the repository owner privately through their GitHub profile and ask for a secure reporting route. Do not publish details while arranging contact.

Include the affected commit/version, exact component, reproduction steps using synthetic files, demonstrated impact, and redacted logs. Never attach a real resume or live token.

The local matching engine processes data locally. When a user chooses Claude integration, relevant resume/job content is sent to Claude under that user's Claude account and privacy settings. This project is not a hiring decision system and its score is not a measure of a person's employability.
